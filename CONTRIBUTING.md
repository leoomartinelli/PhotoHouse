# Como contribuir

Que bom te ver por aqui. A House de Criatividade junta creative minds for the kingdom, e este é o combinado para a gente criar junto, com clareza e com cuidado.

## 1. Git e review

Trabalhe sempre numa branch sua. A `main` é protegida, e ninguém faz commit direto nela.

O nome da branch começa com um destes prefixos:

- `feat/` para coisa nova
- `fix/` para correção
- `design/` para peça visual ou ajuste de interface
- `chore/` para manutenção
- `docs/` para documentação

Abra o pull request apontando para a `main`. Para entrar, ele precisa de pelo menos 1 aprovação do líder.

Use o template de PR. Conte o que muda, como testar, e preencha o checklist.

Bug e ideia viram Issue. O acompanhamento fica no Project da organização, nas colunas **Backlog**, **Em andamento**, **Em revisão** e **Concluído**.

A prioridade fica no campo **Priority** do Project: Urgent, High, Medium ou Low. Label não define prioridade.

Os commits são curtos e levam um prefixo na mensagem:

- `FEAT:`
- `FIX:`
- `DOCS:`
- `CHORE:`

## 2. Antes de abrir o PR

Antes de pedir review, confira:

- [ ] O caminho principal foi testado localmente
- [ ] O build termina sem erro
- [ ] A issue está linkada com `Closes #n`, quando houver uma
- [ ] O diff não leva segredo (token, senha, chave ou `.env`)

## 3. Setup local

Cada projeto explica o próprio setup no README dele. Comece por lá:

- [PreHouse](https://github.com/HOUSE-DE-CRIATIVIDADE/PreHouse)

Se alguma coisa travar no caminho, pergunta cedo: a House está aqui para criar junto com você.
