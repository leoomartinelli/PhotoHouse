preservadas, da imagem **Mascote Engrenagem em Explosão Colorida.png** fornecida
pelo solicitante nesta conversa em 17/10/2026 para testar o design da issue #5.

declara a arte como domínio público nem concede uma licença geral a terceiros.

O GIF final será fornecido posteriormente pelo solicitante. A arte não foi
incorporada ao editor ou aos instaladores nesta etapa.
