# Housinho — animação e alternativa estática

`housinho-base.webp` é uma cópia comprimida, com proporções e composição
preservadas, da imagem **ILLUSTRATOR-JANELA-DE-ABETURA.png** (912 × 1055) fornecida
pelo solicitante nesta conversa em 17/10/2026 para testar o design da issue #5.

O solicitante autorizou o uso no protótipo e seu versionamento nesta branch/PR.
Autor e licença pública não foram informados. Esta autorização específica não
declara a arte como domínio público nem concede uma licença geral a terceiros.

`housinho.gif` é o arquivo original **Sem título - 17 de outubro de 2026 às
14.32.19.gif**, fornecido pelo mesmo solicitante em 17/10/2026 para substituir
a ilustração no estudo. Tem 490 × 566 pixels, 52 quadros de 80 ms (4,16 segundos)
e loop contínuo. O arquivo foi copiado sem alterações. A mesma autorização
específica de uso no protótipo e versionamento nesta branch/PR se aplica;
nenhuma licença pública ou autoria adicional foi informada.

A imagem estática é usada quando o sistema pede movimento reduzido.
Os assets não foram incorporados ao editor ou aos instaladores nesta etapa.
