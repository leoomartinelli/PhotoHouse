# Workflows do upstream

Receitas preservadas do PhotoCraft antes da primeira publicação do PhotoHouse.
Estes arquivos não são executados pelo GitHub Actions nesta pasta.

Referências a repositórios, fontes, segredos, marcas e processos da ArtCraft
precisam ser revistas antes de reutilizar essas receitas na House.

O CI ativo está em `.github/workflows/ci.yml`. A versão automática segue o
template da organização em `.github/workflows/versao.yml`.
